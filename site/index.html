adblitz

Block ads in every app, not just your browser.

adblitz filters traffic for your whole Windows PC at the network level, so there is no browser extension to install and no extension limits to work around.

Download for Windows

Version 0.1.0 · 64-bit · 13.9 MB

What it does

Blocks at two layers

A local DNS resolver blocks ad and tracker domains for all apps. A local filtering proxy applies uBlock Origin and Adblock Plus rule syntax to each request.

Pages don't notice

Blocked requests get a harmless placeholder response instead of a connection error, which avoids many broken pages.

Strips YouTube ads

Ad data is removed from YouTube's responses before they reach the player.

Finds hidden trackers

CNAME uncloaking catches trackers disguised as a site's own subdomains.

Warns about threats

Known malware and phishing domains are blocked, with a warning page in the browser and a Windows notification.

Stays in your control

A tray icon and dashboard show what was blocked. Allow ads on a site with a right-click, or pause everything for up to 6 hours.

Install

  1. Download and run adblitz.exe.
  2. If Windows SmartScreen appears, choose More info, then Run anyway. adblitz is not code-signed yet.
  3. Approve the administrator prompt. Blocking starts right away and resumes each time you sign in.

Before you install

adblitz decrypts your HTTPS traffic on your own PC so it can filter it. To do that it adds a root certificate, unique to your install, to Windows' trusted store. Only install it if you are comfortable with that.

  • System changes: it points Windows' proxy and DNS settings at itself, and adds the certificate, a Firefox policy and a logon task. If adblitz stops, browsers go direct and DNS falls back to your original servers.
  • Local key: the certificate's private key is generated on your PC and is designed never to leave it.
  • Sensitive hosts: hosts on the exclusions list are passed through without being decrypted, and so are private network addresses.
  • Coverage: apps that ignore the Windows proxy still get DNS blocking, but not per-request filtering.
  • VPNs: proxied browser traffic leaves from adblitz, so per-app VPN rules don't apply to it. adblitz warns you when a VPN is connected.
  • uBlock Origin: adblitz is meant to replace it, not run beside it.

Uninstall

Go to Settings > Apps and uninstall adblitz. This restores your network settings and removes the certificate, Firefox policy, logon task and program files.
